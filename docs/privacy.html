IMAGEGRAB / PRIVACY

权限与隐私说明

图片处理在本机完成。预览与下载仍需向图片原站发起网络请求；扩展不把图片另行上传到额外的处理服务。

会读取哪些内容

你主动触发采集后，扩展读取当前页面中的图片链接、尺寸、图片说明等信息，并记录来源页面标题与地址，用于整理和展示图库。已配置的站点会加载内容脚本，以显示采集入口。

这些权限用来做什么

activeTab
在你点击扩展入口后，临时访问当前标签页。
scripting
按需注入图片采集脚本。
downloads
创建下载任务并读取任务进度，保存选中的图片。
storage
在本机保存采集会话与使用设置。
contextMenus
提供右键菜单的图片提取入口。
host_permissions
允许访问清单中列出的电商站点、图片 CDN 和本地测试地址，用于站点适配与取回图片。具体范围可在扩展 manifest.json 中查看。

数据保存在哪里

采集结果保存在浏览器会话存储 chrome.storage.session，设置保存在 chrome.storage.local。下载文件由浏览器保存到本机下载目录。扩展没有另外配置的图片上传或分析服务。

什么时候会发起网络请求

生成缩略图或下载图片时，浏览器会请求对应的图片服务器。图片原站可能据此收到正常网络连接信息。原站访问限制、图片域名授权和网络状况，都可能影响取图结果。

官网与外部链接

官网使用随站点提供的样式、脚本、字体栈和图片，没有嵌入第三方统计脚本。下载按钮指向本站的 ZIP 文件；点击 GitHub 链接会进入 GitHub。网站托管服务自身可能保留访问日志。
