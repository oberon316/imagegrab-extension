常见问题

你可能还想知道。

下载后，怎样安装到浏览器？

先解压 ZIP，再打开 chrome://extensions，开启开发者模式，点击「加载已解压的扩展程序」。选中直接包含 manifest.json 的目录。网页下载按钮不会直接安装扩展。

为什么有些图片没有提取到？

图片可能还未加载。请回到原页面向下滚动，再点击「重新扫描本页」。当前版本采集顶层页面，无法保证取得 iframe 内或尚未出现在页面中的图片。

下载出来的图片是什么格式？

统一为 PNG。JPG、WebP 等可解码图片会重新编码；原本已是 PNG 的图片可以保留原始字节。动态图片转换后保存为静态图片。

为什么预览正常，下载却失败？

原站访问限制、网络异常或图片域名未获扩展授权，都可能导致取图失败。请查看图库中的错误信息，确认原因后重试。

可以在 Edge 或其他浏览器使用吗？

当前清单要求 Chrome 120 或更新版本。Edge 可在 edge://extensions 尝试加载，具体兼容性需要自行验证。当前没有提供 Firefox 和 Safari 安装包。

更新插件后，需要重新安装吗？

下载新版本并解压到固定目录，在扩展管理页重新加载。更新后刷新正在使用的商品页面。不要删除或移动浏览器正在加载的插件文件夹。
