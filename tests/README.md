# tests/ — 测试素材与用例

**状态：尚未生成素材文件。** 本文件先固定用例编号与预期结果，素材页在 [PLAN.md](../PLAN.md) 的 M1～M4 过程中逐个补齐。实际执行结果记录到 [TESTING.md](../TESTING.md)。

## 为什么需要自建素材页

真实网站会变，且无法针对单一特性做隔离验证。这里自建的每个页面只考察一类图片来源，使得"采集结果是否完整"可以被人工逐条清点，不需要猜测。素材图片统一放在 `tests/fixtures/assets/`，使用体积很小的 PNG/SVG，页面中标注预计数量。

## 目录结构

```
tests/
├─ README.md               本文件
├─ local-server.mjs        本地静态服务器（默认 http://localhost:8787）
├─ fixtures/
│  ├─ fixture-basic.html
│  ├─ fixture-lazy.html
│  ├─ fixture-css-bg.html
│  ├─ fixture-srcset-picture.html
│  ├─ fixture-iframe.html
│  ├─ fixture-iframe-inner.html
│  ├─ fixture-edge.html
│  ├─ fixture-long-page.html
│  └─ assets/              小尺寸测试图片（PNG 与 SVG）
└─ tmp/                    临时产物，已被 .gitignore 忽略
```

## 启动测试环境

```bash
node tests/local-server.mjs
# → http://localhost:8787/fixture-basic.html
```

不要用 `file://` 打开素材页：内容脚本的注入与 `fetch` 在该协议下受限，会得到与真实使用不符的结果。
